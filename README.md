### 🛠️ About This Project

A custom GitHub profile card featuring an Arch Linux aesthetic, live GitHub profile statistics, and a pastel syntax-highlighting color scheme.

- 🐧 **OS:** Arch Linux
- 💻 **Languages:** Python, JavaScript, C++
- 🎨 **Theme:** Pastel coding colors
- ⚙️ **Generator:** Python

### 🚀 Generate Your Profile SVG

1. Clone this repository.
2. Edit `profile.txt` to customize your profile details and colors.
3. Run the generator:

   ```bash
   python generate_profile.py
   ```

4. Commit and push the generated SVG files to your repository.
